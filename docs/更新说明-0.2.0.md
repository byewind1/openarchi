# OpenArchi 0.2.0 更新说明

OpenArchi 是开源的原生桌面建筑设计工作台，本版集中在底图参照与概念方案推敲。

## 新增

- DWG/DXF 工作表底图，以及使用同一变换的二维和三维参照。
- 概念体量的轮廓、曲边与高度编辑，支持二维/三维调整。
- 共享模型命令上的 Agent 接入、可检查操作与持续保存；能力以具体入口为限。

## 修复与整理

- 导航过程中合并恢复写入，保留已确认修改的恢复保护。
- 完善保存、重新打开、撤销和重做的相关路径。
- 分开提供 Windows x64、M 系列 Mac 与 Intel Mac 包，替换默认示例为原创合成场景。

## 已知限制

软件仍处于早期阶段，不承诺生产适用性。DWG 依赖用户自行安装的兼容转换器；部分图元、文字和代理实体可能遗漏。底图不会自动转为建筑模型，AI 不会自动完成建筑设计。部分交互仍需完善，Windows 的外部 MCP 接入范围不同。

软件版本与文件格式独立：可读取已支持的旧文件，使用新功能的文件可能被旧程序拒绝。请保留独立备份。macOS 包为 ad-hoc 签名、未公证；Windows 包未使用发行者证书签名。
