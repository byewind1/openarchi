## 可以从脚本确认的行为

该文件是基于已有剖面线稿的楼梯详图辅助工具集，不是输入踏步数后从空白生成整座楼梯的参数化建模器。

- `stbottom`：拾取楼梯剖面线，以厚度默认 100（脚本绘图单位，通常为毫米）生成楼梯板底边；实际扫描、分段由 `svbeam1` 完成。
- `stpflt`：从已有楼梯剖面线的两个端点创建休息平台边线，平台厚度默认 80；涉及相邻线的端点调整和打断。
- `handrail`、`handrail1`：沿已有剖面楼梯线绘制扶手线，读取 `_sthdh` 作为高度；处理遮挡线的选项分别涉及打断/修剪和虚线线型。
- `connrail`：选择两组已有栏杆接头线并补画连接；接头伸出长度默认 150。
- 源码中还包含拾取楼梯剖面、楼层/图层匹配、相交检测、线段延伸与打断等辅助流程。

## OpenArchi 直跑楼梯工作流契约

- **入口与交互：**从 Toolbox 的 Stair、Design → Architectural Tools → Stair，或快捷键 **S** 进入参数设置。无需预先选择构件。设置有效后点 **Start Drawing**，在平面依次点击跑梯起点和终点；终点同时确定跑长与方向。Escape 取消当前绘制并回到选择工具。
- **参数、单位与校验：**长度单位为米；默认宽 1.10 m、总高 3.20 m、18 个踏步、梯板厚 0.10 m、扶手高 1.00 m。宽度范围 0.50–5.00 m，总高 0.10–10.00 m，踏步数 2–100，梯板厚 0.05–0.50 m，扶手高 0.50–1.50 m，跑长至少 0.30 m。非法参数不会创建构件；设置对话框可取消。
- **模型效果：**楼梯是项目模型中的单一稳定 ID 构件。平面显示轮廓和踏步线；3D 由同一参数生成封闭梯段实体和两条扶手中心线。选中后可在两种视图及 ⌘T 属性对话框编辑；属性应用进入撤销历史。复制、移动、旋转、镜像、跨层和 JSON 保存/恢复作用于该参数化构件。
- **明确排除：**只支持直跑；没有转角/多跑、休息平台构件、栏杆立柱、规范校核、任意既有线稿修剪/打断以及 Marquee 体裁切。Tracker 数值放置楼梯尚未接入。
- **可复现验收：**启动 `dist/OpenArchi.app`；选 Stair 或按 S，保留默认值并开始绘制，在平面点击相距约 4.8 m 的两点；按 F3 确认看到实体梯段与扶手；按 ⌘T 修改宽度并应用，确认平面/3D 同步，再按 ⌘Z 恢复；保存后重新打开 JSON，确认楼梯参数保留。自动化测试覆盖建模、参数、撤销/重做、序列化和设置窗状态；本轮未执行该清单的原生桌面实机验收。
