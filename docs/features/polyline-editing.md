# Polyline node and segment editing

## Evidence and limits

- Archicad 29 official help says the Pet Palette is opened by selecting an element, moving over an editable node, edge, or surface, then clicking. Available commands depend on selected element, node/edge/surface, and view; the user may change commands before finishing. [Pet Palettes](https://help.graphisoft.com/AC/29/INT/_AC29_Help/020_Configuration/020_Configuration-27.htm)
- The official node editing page says Move Node repositions a polygon element node and can merge it into a neighbor. [Move Nodes](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-91.htm)
- The official node insertion page confirms polygon edges can receive new nodes via the Pet Palette. [Adding Element Nodes](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-90.htm)
- Graphisoft's public guide says to select an element, click an edge to open the Pet Palette, choose **Insert new node**, then click to set the new node location; on polygon-type elements this adds an edge. It also says a double-click can insert without moving when Insert Node is already active. [Adding Element Nodes](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-90.htm)
- The Move Node guide confirms polygon nodes can be repositioned from the Pet Palette. [Move Nodes](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-91.htm)
- Graphisoft's public guide explicitly calls the edge operation **Offset edge**: it offsets an entire side and stretches neighboring edges; the guide says this polygon reshaping behavior also applies to chained elements. [Reshaping Polygons and Chained Elements](https://helpcenter.graphisoft.com/user-guide/136853/)
- The official fillet/chamfer page describes applying the operation to one polygon corner from the node Pet Palette, or all corners from the reshape command. Fillet produces an arc; chamfer cuts the corner with a straight segment. [Create a Fillet or Chamfer](https://help.graphisoft.com/ac/25/int/_ac25_help/030_Interaction/030_Interaction-92.htm)
- Archicad 29 public help documents **Offset All Edges** as a whole polygonal-element operation with a proportional enlargement/reduction preview. [Offset All Edges, AC29](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-75.htm)
- Archicad 30 documents **Curve edge** as dragging an edge to curve it; Archicad 19 states that the resulting arc crosses both endpoints and the dragged point. [Curve/Straighten Element Edge, AC30](https://help.graphisoft.com/AC/30/INT/Topics/030_Interaction/030_Interaction-92.html) · [Curve/Straighten Element Edge, AC19](https://help.graphisoft.com/AC/19/INT/AC19Help/02_Interaction/02_Interaction-112.htm)
- The requested constant-distance inward/outward offset is a product requirement and differs from AC29 help's proportional contour resize. The exact requested palette layout and live pointer feedback have no runtime observation in this task; REA tools are unavailable, so this note does not claim a runtime investigation.
- Reference evidence confirms Curve edge bends a selected edge through its endpoints and the drag point; it does not establish Archicad's internal storage. The user's product requirement here is explicit: a curved segment is one circular arc controlled by its endpoints and radius, with no intermediate Polyline nodes. Runtime observation of Archicad's drag and radius display was not performed for this change.
- **OpenArchi design:** store arc metadata per segment and tessellate only for drawing and geometric hit checks. The vertex list remains the only editable node list. Dragging the Curve edge preview recalculates the circle from the pointer on every frame; a valid release commits one undo step. This is an independent implementation choice, not a claim about Archicad internals.

## OpenArchi workflow contract

- **Goal:** edit an existing 2D Polyline from its plan nodes or edges, with an undoable floating command palette.
- **Entry:** with Select active, click a Polyline to select it. Press and drag from any part of the selected Polyline, including an endpoint or node, to move the whole object; this gesture does not enter node-edit mode. Release a click on a node to open that node's palette. Clicking a segment opens its edge palette without inserting a node. Choose Insert node explicitly, then drag on that segment and release to confirm.
- **Node edit:** after a click-release opens the node palette, use its active node command to drag the node. Its two incident segments update live; releasing commits a single undoable operation. A direct press-drag from the unedited Select state always moves the whole Polyline.
- **Palette commands:** the inserted-node palette defaults to Move node; dragging the new node previews both incident segments and releasing commits. Chamfer/Fillet opens a compact settings panel and applies the typed length/radius to the active corner. Offset Polyline previews a constant-distance displacement of the complete path; drag toward the interior for an inward offset and toward the exterior for an outward offset. Curve edge previews a circular arc through the contextual segment's endpoints and the dragged point. The preview updates while dragging and displays the resulting radius; the segment keeps only its two endpoint nodes. Move translates the Polyline; Rotate uses the selected node/edge as pivot; Mirror reflects across a user-defined axis; Multiply places a user-selected number of evenly spaced copies on release (default 2). A command can be changed before confirmation.
- **Units and limits:** coordinates and dimensions are metres. Inserted nodes are projected onto the selected straight segment or circular arc; arc subdivision preserves the circle. A placement leaving less than 0.01 m on either side is rejected without mutation. Chamfer length and fillet radius default to 0.25 m and must be finite and positive. A corner edit must leave both incident straight remnants at least 0.01 m long. Offset distance is the pointer movement component perpendicular to the contextual edge, applied to every Polyline edge; adjacent shifted lines meet at their intersections. Open paths shift both endpoints along their end-edge normals. Curve edge requires a non-collinear drag point and stores a radius and sweep; tessellation is view-only. Mirror axis and rotate pivot are defined in plan coordinates by the active node/edge context and pointer gesture.
- **Effects:** every operation updates the shared Project used by plan, properties, and JSON persistence. Successful pointer operations are one undo transaction. Invalid geometry is rejected and the pre-operation model is restored. Multiply creates a new stable element ID and selects the copy.
- **Cancel:** Escape discards the active preview/settings and returns to Select according to the existing two-stage Escape rule. Releasing a valid drag confirms it.
- **Exclusions:** direct numeric radius/angle entry, deleting nodes, multi-node selection, numeric Tracker input for these edit gestures, and 3D Polyline display.

## Acceptance checklist

1. Select a Polyline, then click a node; verify the floating palette and active node marker appear.
2. Click a segment midpoint; verify no node or undo entry is created. Choose Insert node explicitly, drag on the selected segment and release; verify both segments remain connected and one undo restores the original geometry.
3. From Select with no node palette open, press and drag from a node/endpoint; verify the whole Polyline moves and commits once. Then click-release a node to open its palette, drag the active node, and verify its two adjacent lines follow; undo and redo both operations.
4. Use Chamfer and Fillet settings on a non-collinear interior node; verify the corner geometry and undo.
5. Drag a selected Polyline body; verify the whole object moves with the arrow cursor and no palette, then undo. From the node palette, choose Offset Polyline; verify all edges move inward/outward together and the node joins remain connected, release, and undo.
6. Choose Curve edge and drag its contextual segment; verify each pointer move changes the radius preview and readout, the curve passes through both endpoints and the pointer, and only the two endpoints appear as editable nodes. Click an existing arc segment and verify it opens arc editing without inserting a node; release, then undo/redo and save/reload.
7. Use Move, Rotate, Mirror, and Multiply; verify visible results and one undo step per operation.
8. Enter zero, non-finite, too-large, or invalid geometry values; verify the model remains unchanged and the edit stays recoverable.
9. Save/reload JSON after edits and verify vertex coordinates, arc radius/sweep branch, and duplicated element identity persist. Load a pre-arc JSON project and verify absent arc metadata defaults to straight segments.

## 2026-10-16 correction contract

The user's current observed requirements supersede the earlier single-click insertion shortcut above. Clicking a selected straight or curved edge opens its palette without changing the vertex list or undo history. Curve edge acts on that entire contextual segment, retaining its endpoints and node count. During dragging the displayed arc and radius are evaluated from the current pointer before painting; release commits once and Escape restores the original project. Insert node is a separate explicit edge command: drag to project a new node onto the selected straight edge or arc; arc insertion splits the sweep and retains the circle radius and direction. Endpoint placements closer than 0.01 m are rejected. The pencil cursor uses an original long barrel, wooden point, graphite hotspot and end cap.

Evidence: user report and readable OpenArchi source; no new Archicad runtime observation is claimed. Remaining gaps include numeric arc input, straighten command, edge-only offset and complete AC29 palette equivalence. Acceptance: edge click leaves model/history unchanged; bend two different pointer positions without changing nodes; insert into straight and curved edges only after selecting Insert node; cancel, undo/redo and JSON round-trip retain expected geometry.
