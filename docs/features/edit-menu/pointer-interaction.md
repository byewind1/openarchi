## 先纠正此前结论

`⌘D/⌘E/⌘M` 接到数值模态对话框，只说明入口有绑定。它没有复刻用户要求的鼠标跟随、交互中切换复制模式、点击放置和继续多重复制。以后不得用“快捷键可调用同名菜单函数”证明整套编辑操作一致。

证据边界：

- 用户在本轮描述：Cmd+D 激活后鼠标移动驱动移动；过程中 Alt 切换复制，再按 Ctrl 切换多重复制；旋转、镜像也应具有相应交互。
- public documentation：本笔记引用的 AC29 INT 官方帮助，访问日期 2026-10-28。
- readable shipped configuration：Standard Shortcuts 29 XML；全部记录见[标准快捷键总表](standard-shortcuts-full-29.md)和[JSON](standard-shortcuts-full-29.json)。
- readable source：OpenArchi `src/app/edit_shortcuts.rs::edit_shortcuts` → `src/app/edit_menu.rs::dispatch_edit` → `edit_dialog_ui`。现状仍是数值对话框。
- 本轮没有目标运行时手势观察、没有新增 REA Evidence ID；不能把用户报告、帮助和本机实测混写。
- 本机身份复用确认：AC29 INT 5101；可执行文件 SHA-256 `d86af90a1fc90f0a9ef2c8565300179acc9735dda8fc3e0fe07611e8aa8b5505`。

## 1. 必须分开的两层按键

**命令入口层**：选择构件后，按组合键激活一个编辑过程。

| 入口 | 本机标准 macOS 按键 |
|---|---|
| 拖动 / 旋转 / 镜像 | ⌘D / ⌘E / ⌘M |
| 拖动副本 / 旋转副本 / 镜像副本 | ⌘⌥D / ⌘⌥E（另有 ⌘⌥R）/ ⌘⌥M |
| 快速逆时针 / 顺时针 90° | ⌘R / ⌘⇧R |
| 阵列 Multiply | ⌘U |
| 提升 / 缩放 / 调整 | ⌘9 / ⌘K / ⌘− |
| 撤销 / 重做 / 重复上次命令 | ⌘Z / ⌘⌥Z / ⌘B |
| 全选 / 查找选择 | ⌘A / ⌘F |
| 成组 / 解组 / 暂停成组 | ⌘G / ⌘⌥G / ⌥G |
| 工具设置 / 编辑所选构件集 | ⌘T / ⌘⌥T |
| 吸取 / 注入参数 | ⌥C / ⌘⌥C |

**过程修饰层**：命令已经激活后，用修饰键改变当前编辑模式，不重新打开对话框，不重置已经输入的基点/轴。

| 平台 | 单副本模式 | 多副本模式（官方明确支持 Drag/Rotate） |
|---|---|---|
| macOS | Option/Alt | Command + Option/Alt |
| Windows | Ctrl | Ctrl + Alt |

单副本显示 `+`；放置后选中新副本。多副本显示 `++`，连续点击放置，双击结束；旋转多副本保持同一旋转轴。[官方复制说明](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-95.htm)

这些是不同阶段的事件：例如“⌘⌥D 激活拖动副本”和“⌘D 激活后按 Option 切换复制”不能只实现其中一个。

## 2. 鼠标交互步骤

### 拖动 Drag

先选中构件并激活 Drag，鼠标移动决定位置，点击放置；单副本保留原件，多副本可持续放置并双击结束。3D 拖动受当前编辑平面约束。[AC29 Dragging Elements](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-71.htm)

用户进一步明确期望：Cmd+D 激活后移动鼠标才更新移动预览，不能立即以固定 0.5/1 m 位移提交。**菜单/快捷键入口是否还需一次点击定义拖动起点、鼠标所在位置能否直接作为起点，帮助此页没有完整区分；应按入口分别实测。** 不将宠物面板已知热点的行为直接套到菜单入口。

### 旋转 Rotate

选中后激活旋转；点击旋转中心，再点击起始半径位置，随后移动鼠标确定角度，点击完成；也可通过 Tracker 输入角度。快速 90° 旋转是另一个立即执行的命令，不能与多步骤旋转混用。[AC29 Rotating Elements](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-72.htm)

### 镜像 Mirror

激活后用两次点击定义镜像轴，第二次点击完成。它不是固定绕世界 X/Y 轴镜像，也不是数值输入 Origin X 就覆盖了全部操作。门窗的宿主约束是单独特例，不沿用一般独立构件的自由镜像。[AC29 Mirroring Elements](https://help.graphisoft.com/AC/29/INT/_AC29_Help/030_Interaction/030_Interaction-73.htm)

## 3. 冲突和未决项——不得静默猜测

1. **物理 Ctrl 与 Cmd**：用户描述“Alt 后再按 Ctrl”；官方 Mac 复制页写 Cmd+Option。原样保留用户报告，不能擅自判定用户记错，也不能写成 Mac 物理 Control 已证实。下一次对照需记录 ⌃/⌘ 实际键值。
2. **按一下切换还是按住生效**：复制页使用 press，并描述再按一次撤销复制，但重复按键的说明使用了 Ctrl 表述。Mac 的 key-down、key-up、锁存、重复按键和放开顺序未实测；不能先把它实现成 `mode = modifiers.alt` 就声称符合。
3. **镜像多重复制**：用户希望镜像同类交互；帮助明确的多副本段只列 Drag/Rotate，本机既有菜单盘点也没有 Mirror Multiple Copies。单次镜像复制有依据，多重镜像目前为待确认要求。
4. **旋转副本入口冲突**：旋转帮助页有 Cmd+Shift+E/R 的文字；本机 macOS 标准 XML 却给 Rotate a Copy 配置 Cmd+Option+E/R，Cmd+Shift+R 为快速顺时针旋转。入口映射以已记录版本/方案为依据，保留文档冲突，不覆盖标准配置。
5. **多副本后的 Esc 和 Undo**：双击结束有文档依据；Esc 是否只取消下一份预览、保留已放置份数，以及每次放置还是整段会话构成一次 Undo，尚未实测。
6. **全量范围**：171 条是标准 XML 的完整记录，不是所有用户自定义/固定/手势/GDL 快捷键的全集。实际方案由 Work Environment 决定。[官方快捷键说明](https://help.graphisoft.com/AC/29/INT/_AC29_Help/020_Configuration/020_Configuration-25.htm)
7. **3D 范围**：各帮助页对可用元素/视图的描述不同，不从平面通过推断全部 3D 编辑通过。

## 4. 后续实现契约（设计建议，不是已观察事实）

建议把“几何输入阶段”和“复制模式”作为正交状态：

- 几何阶段：Idle → 等待必要基点 → 等待方向/半径/轴点 → 随鼠标预览 → 确认放置。
- 变换类型：Drag / Rotate / Mirror。
- 复制模式：MoveOriginal / CopyOnce / CopyMany；Mirror 的 CopyMany 保持未核准，不因枚举存在就向 UI 开放。
- 会话保存不可变原始构件、选择、鼠标/吸附点、已确认中心/轴、工作平面。每帧从原始几何推导预览，避免在上一帧结果上累计漂移。
- 修饰键只改变模式和 `+ / ++` 光标反馈；不丢失已经定义的基点或旋转中心；快捷键按键释放不应立即终止操作。
- 预览与持久化模型分离。确认时使用同一类型化模型操作做锁定、图层、宿主、几何有效性检查；失败不产生半个模型变更。
- 启动和移动预览本身不制造 Undo 记录；最终 Undo 粒度按未决项实测决定。复制保留完整元数据并重映射宿主/组 ID。
- Tracker 是交互中的精确输入通道，不以模态数值对话框替代鼠标操作。文本输入与裸字母工具热键的优先级单独验证。
- 平面/3D、选择、属性、保存重开共用模型结果；临时预览不得进入自动保存。

## 2026-10-28 Cmd+D 修正实施

用户明确要求 Cmd+D 不弹对话框。本次实现 `PointerDrag`：快捷键与菜单 Drag、Drag a Copy、Drag Multiple Copies 共用鼠标会话；起点采用激活前画布内最后鼠标位置，没有位置时采用首次进入画布的位置。鼠标移动只绘制独立轮廓预览，单击提交类型化 Transform，Esc/右键取消当前预览。平面及三维当前楼层水平面使用同一模型操作。Shift 约束主轴。

OpenArchi 可逆交互选择（非 AC29 实测结论）：Option 按下切换单副本并锁存，Option+Cmd 进入多副本；同时接受用户指定的 Option+物理 Ctrl。松开不退出复制。多副本每次单击单独形成 Undo，近位置双击结束且第二击不重复放置，Esc 保留已经放置的副本。旋转、镜像仍是先前数值对话框，不包含在此次 Cmd+D 修正中。Tracker 精确数值输入、对象吸附和任意三维编辑面尚未接入此会话。

预览不替换项目，锁定检查、宿主跟随、复制 ID、保存数据与撤销继续交给既有 EditCommand::Transform。新增事件测试覆盖无模态、预览不改模型/历史、落点、Esc、Option 锁存、多次放置、锁定拒绝、三维水平面、序列化及撤销。测试与新包结果见 docs/validation.md 本次条目。

待确认的新增经验候选：连续放置的结束条件应同时检查双击事件与落点距离，避免把快速点击不同位置误判为结束；复制修饰键应优先于参数吸取/注入光标。

## 2026-10-28 Cmd+D物体上按压取点丢失修复契约

用户报告：激活后点击物体不能继续移动/复制。源码检查：会话不按元素命中过滤，普通完整单击墙体在旧包独立样本可成功；但基点依赖response.clicked，左键按下后立即位移会转为drag而丢失基点。此次明确修复这一已复现输入，不声称普通单击必然失效或再次观察了AC29。
